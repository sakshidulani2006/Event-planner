Engine Architecture

Built for Precision and Transparency

A clean, modular academic implementation without opaque black-box assertions or external API dependencies.

🛡️

Strict Hard Filters

Instantly discards invalid venues through non-negotiable checks: city location, maximum guest capacity, and event type compatibility.

⚖️

Weighted 100-Point Scoring

Compatibility is scored across Event Type (25), Budget Fit (25), Cuisine (20), Rating (15), Capacity Fit (10), and Amenities (5).

🌲

RandomForestRegressor ML

Pretrained Scikit-Learn pipeline deployed via Joblib for instant inference without retraining on HTTP requests.

💬

Explainable Reasoning

Every recommendation provides real bullet-point justifications explaining why the venue fits your specific constraints.

⚡

Zero External APIs

Self-contained Python Flask + Vanilla JS architecture with no Node.js, MongoDB, React, or Firebase overhead.

📊

Transparent Metrics

Evaluated using standard statistical indicators (MAE, RMSE, R²) with honest documentation of synthetic training data.

Starlit Serenity

A full-stack Event Planning & Venue Recommendation System designed as a modular, transparent academic project. Incorporates rule-based multi-attribute decision making and Scikit-Learn regression modeling.

Dataset: 160 curated Indian venues (synthetic guest distributions for demo/training).

Technology Stack

  • Frontend: HTML5, CSS3, Vanilla JS (ES6)
  • Backend: Python 3.13, Flask, Flask-CORS
  • ML / Analytics: Pandas, NumPy, Scikit-learn
  • Persistence: Joblib Pipeline (.pkl)

API Endpoints

  • GET /api/health
  • GET /api/options
  • POST /api/recommend
  • POST /api/predict-budget
